# Mark

Mark is a professional productivity and habit tracker web app built with React and Vite.

## Features

- Overview dashboard with productivity metrics, goals, schedule, reminders, focus timer, and check-ins
- Calendar view for time-blocked tasks
- Task queue with scheduled and unscheduled work
- Goals dashboard connected to daily work
- Focus session console with check-in logging
- Habit tracker with weekly completion toggles
- Analytics dashboard for focus, completion, goals, and habit consistency
- Check-ins timeline and daily reflection composer

## Development

```bash
npm install
npm run dev
```

The web app runs locally at `http://127.0.0.1:5173/`.

## Build

```bash
npm run build
```

## Environment

TRY IT.

Set these variables in local `.env.local` and in the Vercel project:

```bash
VITE_SUPABASE_URL=
VITE_SUPABASE_PUBLISHABLE_KEY=
```
